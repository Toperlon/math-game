# 🧮 math-game

**math-game** — это динамичная интеллектуальная игра с графическим интерфейсом, созданная для проверки скорости мышления и математических навыков. Игроку предстоит столкнуться со случайными вызовами из разных разделов математики, зарабатывать очки за правильные ответы и удерживать высокий процент игровых побед. 

Игра выполнена в стильном темном интерфейсе (**Cyberpunk / Dark Mode**) с мгновенным аудио- и визуальным откликом на действия игрока.

---

## 🎮 Игровые Механики и Режимы

В игре реализован генератор случайных игровых событий. Каждый раунд предлагает одну из **9 уникальных математических дисциплин**:

| Название режима | Что нужно делать? | Диапазон сложности |
| :--- | :--- | :--- |
| **➕ Сложение / ➖ Вычитание** | Быстрый подсчет базовых выражений | Числа от 1 до 250 |
| **✖️ Умножение** | Классическая таблица умножения | Числа от 1 до 15 |
| **🔍 Найти X** | Решение линейных уравнений вида `b * x = c` | Поиск неизвестного `X` |
| **平方 Возведение в квадрат** | Вычисление второй степени числа | Числа от 1 до 100 |
| **⚖️ Сравнение** | Быстрое определение знаков `<`, `>`, `=` | Числа от -1000 до 1000 |
| **❓ Угадай знак** | Восстановление пропущенного оператора (`+`, `-`, `*`, `/`) | Случайные уравнения |
| **📏 Модуль числа** | Вычисление абсолютного значения разности `\| a - b \|` | Отрицательные и положительные числа |
| **🎯 Округление числа** | Округление дробного числа до целого | Дроби с точностью до сотых |

## ✨ Ключевые Особенности

*   **⚡ Интерактивный UI Feedback:** Поле ввода мгновенно реагирует на ответ: окрашивается в **зеленый** цвет при победе и в **красный** при ошибке (с автоматическим сбросом через 300 мс, чтобы не отвлекать от геймплея).
*   **🔊 Звуковое сопровождение:** Интеграция с системными звуками Windows (`winsound`). Победы, поражения и пустой ввод имеют свои уникальные аудиоэффекты.
*   **⌨️ Управление «вслепую» (Горячие клавиши):** 
    *   `Enter (Return)` — подтвердить и проверить свой ответ.
    *   `Escape` — сбросить текущий пример и активировать «Смену квеста» (штрафуется в статистике).
*   **📊 Расширенная Live-Статистика:** Прямо во время игры рассчитывается винрейт игрока (соотношение побед и поражений в процентах), а также фиксируется количество пропущенных раундов.

## 🏗️ Архитектура Проекта

Код игры спроектирован по канонам легковесных GUI-приложений на Python с разделением на логические слои:

*   **Core-логика (`example`)**: Игровой движок, отвечающий за рандомизацию задач, расчет истинного ответа (`answer`) и динамическое обновление интерфейсных переменных.
*   **Валидатор (`answer_check`)**: Контроллер, обрабатывающий ввод пользователя, управляющий анимацией интерфейса, звуковыми триггерами и перерасчетом игровой статистики.
*   **Дизайн-система**: Выделенный блок констант палитры (цвета фонов, кнопок, главного и акцентного текста) для удобного изменения темы игры.
*   **Компоновка окон**: Двухфреймовая структура (`frame_func` и `frame_stat`) с абсолютным позиционированием элементов для обеспечения монолитности и защиты от сдвигов интерфейса при изменении данных.
